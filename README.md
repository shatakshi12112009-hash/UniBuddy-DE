
# 🇩🇪 UniBuddy DE

### Your mini toolkit for university life in Germany!

UniBuddy DE is a Python project designed to help university
students organise their academic life.

## ✨ Features

- 📅 Add and track exams and assignment deadlines
- 🎓 Estimate workload using ECTS credits
- 🇩🇪 Practise German university vocabulary
- 💾 Save deadlines locally between sessions

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

If needed, use `python3 main.py`.

## 🛠️ Technologies

- Python

- Date and file handling
