A curated guide for university students in Germany, especially
students in their second year of Computer Science.

**Goal:** Find reliable information, study smarter, and prepare
for university projects and internships.

## 💻 2. Second-Year Computer Science Study Guide

Course structures differ between universities. Always use your
own module handbook and examination regulations as the main guide.

### A. Data Structures and Algorithms

Focus on:
- Arrays, linked lists, stacks and queues
- Trees, graphs and hash tables
- Sorting and searching
- Big-O time and space complexity
- Recursion and problem-solving

Study tip:
Implement each data structure yourself, then compare its
operations and time complexity.

### B. Object-Oriented Programming

Focus on:
- Classes and objects
- Encapsulation, inheritance and polymorphism
- Interfaces and abstraction
- Exceptions and testing
- Writing readable, maintainable code

Study tip:
Build a small project using multiple classes and document
why each class exists.

### C. Database Systems

Focus on:
- Relational database concepts
- SQL queries and joins
- Primary and foreign keys
- Database normalization
- Transactions and data integrity

Study tip:
Design a database for a library or student club and practise
writing queries against it.

### D. Operating Systems

Focus on:
- Processes and threads
- CPU scheduling
- Memory management
- Synchronization and deadlocks
- Files and permissions

Study tip:
Create a one-page summary for each major concept and solve
practice questions without looking at your notes.

### E. Computer Networks

Focus on:
- TCP/IP and networking layers
- IP addresses and subnetting
- TCP versus UDP
- DNS and HTTP
- Basic network security concepts

Study tip:
Explain what happens when you enter a website address
into a browser.

### F. Software Engineering

Focus on:
- Git and version control
- Requirements and design
- Unit testing
- Debugging
- Code reviews and teamwork

Study tip:
Use Git commits that explain what changed and why.

**Important:** These are common CS topics, not a universal
second-year syllabus. Follow your own university's curriculum.

## 📚 3. A Practical Weekly Study Routine

- **Before lectures:** Review the previous topic for 15 minutes.
- **After lectures:** Rewrite key ideas in your own words.
- **During the week:** Solve exercises without immediately
  checking solutions.
- **Every week:** Build or improve a small coding project.
- **Before exams:** Practise past papers where permitted and
  review mistakes.
- **Every month:** Update your GitHub portfolio and document
  what you learned.

Consistency is more useful than last-minute cramming.

---

## 🚀 4. Build a Strong CS Portfolio

Try small projects such as:

1. A task manager with file storage
2. A SQL database project
3. A data structures visualizer
4. A simple REST API
5. A collaborative software project

For every project, include:
- A clear README
- A description of the problem
- Setup and usage instructions
- Screenshots, if useful
- Tests, where appropriate
- What you learned and what you would improve

Never upload passwords, API keys or private information.

## 💼 5. Prepare for Internships

- Keep your CV concise and tailored to each role.
- Practise explaining your projects clearly.
- Learn Git, debugging and basic testing.
- Read internship requirements carefully.
- Use your university's career service.
- Check official rules and your individual circumstances
  before making decisions about student employment.
